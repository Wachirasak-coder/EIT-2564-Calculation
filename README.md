# EIT 2564 Calculation

เว็บแอปช่วยคำนวณงานติดตั้งทางไฟฟ้าแรงต่ำ อ้างอิงเลขข้อและเลขตารางของ
**มาตรฐานการติดตั้งทางไฟฟ้าสำหรับประเทศไทย พ.ศ. 2564 (วสท. 022001-22)**
ทุกผลลัพธ์แสดงขั้นตอนคำนวณ (สูตร → แทนค่า → ผล) พร้อมเลขข้อที่อ้างอิง และพิมพ์/บันทึกเป็น PDF ได้

## หัวข้อคำนวณ
| แท็บ | หัวข้อ | อ้างอิง |
|---|---|---|
| ก | โหลดและดีมานด์แฟกเตอร์ (แสงสว่าง เต้ารับ เครื่องใช้ไฟฟ้า ลิฟต์ แอร์ส่วนกลาง นิวทรัล) | ข้อ 3.2, ตาราง 3-1, 3-2, 3-3, 10-2, ภาคผนวก ฌ |
| ข | ขนาดสายไฟฟ้า + ตัวคูณอุณหภูมิ/จำนวนวงจร + ตรวจแรงดันตก | ตาราง 5-20, 5-21, 5-23, 5-27, 5-29, 5-8, 5-43, 5-44 |
| ค | แรงดันตก (ตาราง mV/A/m หรือสูตร R, X) รวมไม่เกิน 5% | ข้อ 3.6, ภาคผนวก ฐ |
| ง | มิเตอร์ เครื่องป้องกันกระแสเกิน ตัวนำประธาน | ข้อ 3.5.2, ตาราง 3-4 (กฟน.), 3-5 (กฟภ.) |
| จ | สายต่อหลักดิน และสายดินบริภัณฑ์ไฟฟ้า | ตาราง 4-1, 4-2, ภาคผนวก ญ |
| ฉ | ขนาดท่อร้อยสาย | ตาราง 5-3 |
| ช | วงจรมอเตอร์ (สายวงจรย่อย สายป้อน เครื่องป้องกันลัดวงจร) | ข้อ 6.3.5–6.3.22, ตาราง 6-1, 6-3 |
| ซ | เครื่องป้องกันกระแสเกินหม้อแปลงระบบแรงสูง | ตาราง 6-5 |
| ฌ | อาคารชุด (โหลดตามพื้นที่ มิเตอร์ห้องชุด โคอินซิเดนต์แฟกเตอร์) | ข้อ 9.1.2, ตาราง 9-1 ถึง 9-6 |

## ค่าตารางมาตรฐาน (สำคัญ)
ตัวเลขในตารางของมาตรฐานเป็นลิขสิทธิ์ของ วสท. **repo นี้ไม่มีตัวเลขเหล่านั้นแบบอ่านได้**
- `data/tables.enc.json` — ค่าตารางแบบเข้ารหัส (AES-256-GCM, กุญแจจากรหัสผ่านด้วย PBKDF2-SHA256 300,000 รอบ) ไม่มีรหัสผ่านอ่านไม่ได้
  เปิดเว็บครั้งแรกบนแต่ละเครื่อง ใส่รหัสผ่านครั้งเดียว เบราว์เซอร์จะจำค่าไว้ (ปุ่ม "ล้างข้อมูล/ล็อกเครื่องนี้" ใช้ลบออก)
- `data/tables.template.json` — โครงสร้างไฟล์ (ค่าเป็น `null`)
- `data/tables.local.json` — ไฟล์ค่าจริงบนเครื่องผู้ใช้ อยู่ใน `.gitignore` ไม่ถูกอัปโหลด
- แก้ค่าตารางแล้วสร้างไฟล์เข้ารหัสใหม่: `node tools/encrypt-tables.mjs "<รหัสผ่าน>"` แล้ว commit `data/tables.enc.json`
  (ใช้คำสั่งเดียวกันนี้เพื่อเปลี่ยนรหัสผ่าน)
