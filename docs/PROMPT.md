## PROMPT

คุณคือวิศวกรไฟฟ้าและนักพัฒนาซอฟต์แวร์ ช่วยสร้างเว็บแอป **"EIT 2564 Calculator"** สำหรับคำนวณงานออกแบบระบบไฟฟ้าแรงต่ำ
ตาม *มาตรฐานการติดตั้งทางไฟฟ้าสำหรับประเทศไทย พ.ศ. 2564 (วสท. 022001-22)* โดยมีข้อกำหนดดังนี้

### 1. เทคโนโลยี
- HTML + CSS + JavaScript (ES modules) ล้วน ไม่มี build step เปิดได้ด้วย GitHub Pages และเปิดไฟล์ `index.html` ตรงๆ ได้
- ไม่ใช้ backend ข้อมูลทั้งหมดอยู่ฝั่ง browser
- รองรับมือถือ (responsive) ภาษาไทยทั้งหมด ฟอนต์ Sarabun / Noto Sans Thai
- โครงสร้าง:
  ```
  index.html
  css/style.css
  js/app.js                 # router แท็บ/หน้า
  js/calc/*.js              # ฟังก์ชันคำนวณล้วน (pure function) แยกตามโมดูล
  js/ui/*.js                # ฟอร์มและการแสดงผลแต่ละโมดูล
  data/tables/*.json        # ค่าตาราง (ผู้ใช้กรอก/ตรวจทานเอง) แต่ละไฟล์มี field "source": "ตารางที่ x-x"
  tests/*.test.js           # unit test (node --test) พร้อมตัวอย่างคำนวณมือ
  docs/                     # คู่มือ, ที่มาสมการ
  ```

### 2. หลักการสำคัญ
1. **ทุกผลลัพธ์ต้องอ้างเลขข้อ/เลขตาราง** ของมาตรฐาน เช่น "ข้อ 3.6.1", "ตารางที่ 5-20"
2. **แสดงขั้นตอนคำนวณ** (สูตร → แทนค่า → ผล) ให้วิศวกรตรวจได้ และผลสรุป ผ่าน / ไม่ผ่าน
3. **ลิขสิทธิ์**: ห้ามคัดลอกเนื้อหามาตรฐานลงในโค้ด ค่าตัวเลขในตารางเก็บใน `data/tables/*.json` แยกต่างหาก
   ไฟล์ค่าจริง `data/tables.local.json` อยู่ใน .gitignore (repo เป็น Public) แอปนำเข้าไฟล์นี้จากเครื่องผู้ใช้ ข้อความในแอปเขียนสรุปด้วยคำของเราเองพร้อมอ้างเลขข้อ
4. ค่าตารางที่ยังไม่กรอก ให้แอปแจ้ง "ยังไม่มีข้อมูลตาราง x-x" แทนการเดาค่า
5. ใส่ข้อความ disclaimer: ผลคำนวณเป็นเครื่องมือช่วย ผู้ลงนามต้องตรวจสอบกับมาตรฐานฉบับจริง
6. ฟังก์ชันคำนวณต้องเป็น pure function มี unit test ครอบคลุมกรณีขอบ (ค่าศูนย์, เกินตาราง, ปัดขึ้นขนาดมาตรฐาน)

### 3. ระบบไฟที่รองรับ
- 1 เฟส 2 สาย 230 V และ 3 เฟส 4 สาย 400/230 V, 50 Hz
- ตัวนำทองแดง (หลัก) อะลูมิเนียมเป็นตัวเลือก (ตารางที่ 5-42)

### 4. โมดูลเฟส 1
| # | โมดูล | อินพุตหลัก | อ้างอิง |
|---|---|---|---|
| ก | โหลดและดีมานด์ | รายการโหลด (แสงสว่าง/เต้ารับ/เครื่องใช้/แอร์/ลิฟต์), ประเภทอาคาร | ตาราง 3-1, 3-2, 3-3, 10-2, ภาคผนวก ฌ |
| ข | ขนาดสายไฟ | กระแสโหลด, ชนิดสาย/ฉนวน (PVC 70°C, XLPE 90°C), วิธีเดินสาย (ตาราง 5-47), อุณหภูมิโดยรอบ, จำนวนวงจร/สายในท่อ | ตาราง 5-20 ถึง 5-42, ตัวคูณ 5-8, 5-40, 5-41, 5-43, 5-44, 5-45, 5-46 |
| ค | แรงดันตก | กระแส, ความยาว, ขนาดสาย, PF, 1φ/3φ | ข้อ 3.6.1/3.6.2 (≤ 5% รวม), ภาคผนวก ฐ (ตาราง ฐ.1–ฐ.x), ข้อ 5.25.1.10 |
| ง | เครื่องป้องกันกระแสเกิน / ตัวนำประธาน / มิเตอร์ | โหลดรวม, ขนาดมิเตอร์ | ตาราง 3-4, 3-5, ภาคผนวก จ |
| จ | สายดิน | ขนาดตัวนำประธาน, พิกัด OCPD | ตาราง 4-1 (สายต่อหลักดิน), 4-2 (สายดินบริภัณฑ์), ภาคผนวก ญ |
| ฉ | ท่อร้อยสาย | จำนวน/ขนาดสาย, ชนิดท่อ | ตาราง 5-3, ภาคผนวก ฎ |

ขั้นตอนตรรกะของโมดูล ข (ตัวอย่าง):
1. I_design = กระแสโหลด (โหลดต่อเนื่อง/มอเตอร์ × 1.25 ตามข้อที่เกี่ยวข้อง)
2. เลือก In ของ OCPD ≥ I_design (ขนาดมาตรฐาน)
3. ตัวคูณรวม = Ca (อุณหภูมิ) × Cg (จำนวนวงจร/กลุ่ม)
4. เลือกขนาดสายที่เล็กที่สุดที่ Iz_table × ตัวคูณ ≥ In
5. ส่งต่อไปโมดูล ค ตรวจแรงดันตก ถ้าเกิน ให้เพิ่มขนาดสายอัตโนมัติและแสดงเหตุผล
6. ส่งต่อไปโมดูล จ และ ฉ เพื่อหาสายดินและขนาดท่อ

### 5. โมดูลเพิ่มเติม (อยู่ในเวอร์ชันนี้แล้ว)
- ช. วงจรมอเตอร์ (ข้อ 6.3.5.1, 6.3.7, 6.3.21, 6.3.22, ตาราง 6-1, 6-3)
- ซ. หม้อแปลงแรงสูง (ตาราง 6-5)
- ฌ. อาคารชุด: โหลดตามพื้นที่ (ข้อ 9.1.2), มิเตอร์ห้องชุด (ตาราง 9-1 ถึง 9-4), โคอินซิเดนต์แฟกเตอร์ (ตาราง 9-5, 9-6)
- ถัดไป: ระยะที่ว่างปฏิบัติงาน (ตาราง 1-1, 1-2), earth fault loop impedance (ภาคผนวก ญ), รางเคเบิล (ตาราง 5-30 ถึง 5-33, 5-40, 5-41)

### 6. ฟีเจอร์ร่วม
- โหมด "คำนวณทั้งวงจร": โหลด → OCPD → สาย → %VD → สายดิน → ท่อ ในหน้าเดียว
- บันทึก/โหลดโปรเจกต์เป็นไฟล์ JSON, จำค่าล่าสุดใน localStorage
- พิมพ์/ส่งออก PDF รายการคำนวณ (หัวกระดาษ: ชื่อโครงการ, ผู้คำนวณ, วันที่, เลขทะเบียน กว.)
- หน้า "ตารางข้อมูล" ให้ผู้ใช้ตรวจ/แก้ค่าตารางและ export JSON
